# إعداد Postman لـ Task Assistant API

يحتوي هذا المجلد على مجموعات Postman والبيئات لاختبار مساعد المهام باللغة العربية.

## الملفات

- **Task_Assistant_API.postman_collection.json** - مجموعة طلبات API العامة مع نقاط النهاية الشائعة
- **Test_Requests_T01-T10.postman_collection.json** - حالات الاختبار العشرة للتقييم (T01-T10) بقيم ثابتة
- **Local_Environment.postman_environment.json** - بيئة التطوير المحلية
- **Production_Environment.postman_environment.json** - بيئة الإنتاج (حدث الرابط)

## تعليمات الاستيراد

### الطريقة 1: السحب والإفلات (الأسهل)

1. افتح Postman
2. اسحب ملف المجموعة إلى Postman
3. اسحب ملفات البيئة إلى Postman

### الطريقة 2: زر الاستيراد

1. افتح Postman
2. انقر على **Import** في الزاوية العلوية اليسرى
3. اختر ملف المجموعة وانقر على **Import**
4. كرر لملفات البيئة

## استخدام المجموعات

### طلبات الاختبار T01-T10 (اختبارات التقييم)

تحتوي هذه المجموعة على الرسائل العشرة للتقييم مع جميع القيم ثابتة (بدون متغيرات):

1. **0 - فحص الصحة** - التحقق من حالة اتصال PostgreSQL
2. **T01** - سارة تسجّل مهمة لخالد (سجّل مهمة لخالد بكرة الساعة 10 يراجع عرض السعر)
3. **T02** - فهد يحاول إسناد مهمة لخالد (متوقع HTTP 403)
4. **T03** - فهد يذكّر نفسه يوم الجمعة (الترحيل من الجمعة إلى السبت)
5. **T04** - سارة تسند لنورة قسم مختلف (متوقع HTTP 403)
6. **T05** - خالد يسأل عن مهامه (يتطلب تشغيل T01 أولاً)
7. **T06** - نورة تسأل عن مهلة الإجازة (استعلام عن السياسة)
8. **T07** - خالد يسأل عن بدل السكن (المعلومة غير متوفرة)
9. **T08** - فهد يدّعي أنه المدير (متوقع HTTP 403)
10. **T09** - منيرة تسجّل اجتماعًا لعبدالرحمن (الترحيل من الجمعة إلى السبت)
11. **T10** - سارة تسجّل مهمة لاسم غير موجود (يطلب توضيحًا)

**مهم**: شغّل هذه الاختبارات بالترتيب بدءًا من قاعدة بيانات نظيفة:
```bash
docker compose exec server npm run db:reset
# أو
npm run db:reset
```

### مجموعة API العامة

تستخدم هذه المجموعة متغيرات البيئة وتتضمن:
- فحص الصحة
- إدارة المهام (إنشاء، عرض، تعديل)
- استعلامات السياسة (ساعات العمل، العمل عن بعد)
- إدارة الطلبات (إنشاء، عرض، موافقة)
- التقارير (تقديم، عرض)

## استخدام البيئات

1. اختر البيئة من القائمة المنسدلة في الزاوية العلوية اليمنى
2. لاختبارات T01-T10، لا تحتاج إلى بيئة (جميع القيم ثابتة)
3. للمجموعة العامة، اختر "Local" أو "Production"

## تشغيل الخادم

```bash
# Docker (موصى به)
docker compose up -d --build

# أو Node.js محلي
npm start
```

## متغيرات البيئة (للمجموعة العامة)

- `base_url` - رابط API الأساسي (مثلاً `http://localhost:3000`)
- `user_id` - معرف المستخدم الافتراضي للاختبار (2 = موظف، 3 = مشرف، 1 = مدير)

## معرفات الموظفين

يتضمن المشروع 6 موظفين افتراضيين:
- المعرف 1: المدير (منيرة)
- المعرف 2: المشرف (سارة)
- المعرف 3: الموظف (فهد)
- المعرف 4: الموظف (خالد)
- المعرف 5: الموظف (نورة)
- المعرف 6: الموظف (عبدالرحمن)

## المصادقة

للنشر في الإنتاج مع مصادقة الرمز:

1. أضف ترويسة `Authorization` للطلبات:
   - المفتاح: `Authorization`
   - القيمة: `Bearer <your-token>`

2. حدّث متغير البيئة أو أضفه للطلبات الفردية
