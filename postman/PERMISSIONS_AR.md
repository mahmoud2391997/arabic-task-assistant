# استيراد اختبارات الصلاحيات في Postman

اسحب الملفين إلى Postman أو اختر Import:

- [مجموعة الاختبارات](Permissions_Demo.postman_collection.json)
- [البيئة المحلية](Permissions_Local.postman_environment.json)

اختر بيئة «اختبارات الصلاحيات — محلي». عنوانها localhost:3000؛ غيّر `base_url` إلى http://localhost:3180 لنسخة الفيديو المنفصلة.

شغّل Collection Runner بالترتيب، تكرار واحد. الخطوتان 02 و03 تسجلان مهمتين تجريبيتين فعليتين باستخدام Groq. باقي الخطوات تعرض مهام المدير والمشرفين والموظف وتختبر رفض الصلاحيات وحقول الدور المزيفة. تظهر النتائج التلقائية في Test Results.

يُحفظ رقم كل مهمة في متغير المجموعة ثم يُستخدم للتأكد أنها تظهر في النطاق الصحيح فقط. إذا فشل الإنشاء بسبب حصة Groq، لا تعتبر نتائج المتابعة دورة ناجحة؛ انتظر Retry-After وأعد الخطوات بالترتيب. إعادة تشغيل المجموعة تسجل مهمتين جديدتين؛ لا تستخدم قاعدة إنتاج.

هذه اختبارات API في الوضع المحلي AUTH_MODE=demo. ليست بديلاً لاختبار مستودع البيانات المباشر وليست إثباتاً لتفعيل PostgreSQL RLS. الإنتاج يحتاج مفاتيح الموظفين وحماية Vercel، ولا تتضمن هذه الملفات أي مفتاح.
