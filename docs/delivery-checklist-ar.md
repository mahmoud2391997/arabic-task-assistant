# قائمة التسليم

## 01 — الكود الكامل

المصدر: https://github.com/mahmoud2391997/arabic-task-assistant (مستودع خاص؛ يجب منح المقيم صلاحية القراءة)، أو النسخة المضغوطة المرفقة. يتضمن README وأوامر Docker و`.env.example` والاختبارات ومجموعات Postman. ضع مفتاحك في `.env` محلياً فقط؛ ملفات المفاتيح ليست ضمن نسخة التسليم.

التشغيل بعد توفير Docker ومفتاح Groq:

```bash
cp .env.example .env
# ضع مفتاح Groq في .env دون تعديل الكود
docker compose up -d --build
docker compose exec server npm run demo
```

الديمو ينشئ مهام اختبارية؛ استخدم قاعدة منفصلة عن الإنتاج. [إعداد Postman](../POSTMAN_SETUP.md) و[الرسائل العشر](../postman/Test_Requests_T01-T10.postman_collection.json) متاحان لعرض كل طلب ورد أثناء الفيديو.

## 02 — فيديو 3 إلى 5 دقائق بصوت صاحب المشروع

يُرفق التسجيل الشخصي منفصلاً؛ النص ليس بديلاً للفيديو. [النص والترتيب بالعربي](video-script-ar.md) يشرح التشغيل والرسائل العشر والنتائج ومكان تطبيق الصلاحيات في الكود. لا تعرض `.env` أو مفاتيح الوصول أثناء التسجيل. نسخة الفيديو المقترحة لها قاعدة ومنافذ منفصلة.

## 03 — صفحة القرارات بالعربية

أرفق [صفحة القرارات](03-decisions-ar.md): أسباب اختيار الأدوات، تكلفة 100 موظف × 20 رسالة يومياً، وخطة تحسين أسبوع إضافي. الأرقام مبنية على افتراضات معلنة وعينة فعلية؛ لا وعد بخدمة مجانية غير محدودة.

## التحقق وحدود الإثبات

- آخر مراجعة للكود: 56/56 اختباراً ناجحاً مع PostgreSQL الحقيقي؛ لا فشل أو تخطي.
- التشغيل السابق من نسخة نظيفة: الرسائل العشر نجحت فعلياً عبر HTTP وGroq وPostgreSQL؛ الردود محفوظة في [ملف النتائج](evaluation-results.json). الإسناد الجماعي الجديد تحقق أيضاً عبر Groq المحلي.
- جميع قواعد النظام الحالية موثقة في [القواعد](business-rules.md)، بما فيها التغييرات التي طلبها صاحب المشروع بعد الملف الأصلي.
- استقبال Telegram وAPI وحماية النشر اجتازت فحص النسخة المنشورة.
- Groq يخضع للحصة الخارجية؛ عند تجاوزها يرجع 429 دون تنفيذ الطلب. تحقق من توفر الحصة قبل تسجيل الفيديو.
- تسجيل الفيديو نفسه لم يُرفق بعد. المستودع الخاص يحتاج وصول المقيم. CI/CD الآلي يتطلب إعدادات الحساب والأسرار؛ النشر اليدوي تحقق ويعمل.

هذه قائمة تحقق فعلية للتسليم، وليست ضماناً لدرجة تقييم أو غياب كل مشكلة ممكنة.
