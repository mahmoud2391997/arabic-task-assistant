# خطة فيديو التسليم الشخصي — 3 إلى 5 دقائق

يسجل صاحب المشروع الفيديو بصوته. لا يحتوي الفيديو على .env أو المفاتيح أو عنوان webhook السري. أخفِ القيم الحساسة قبل مشاركة الشاشة.

- 0:00–0:30: اشرح مساعد المهام، Node.js وGroq وPostgreSQL، وأن البيانات خيالية للتقييم.
- 0:30–1:00: اعرض README وأمر Docker، ثم فحص health دون أسرار.
- 1:00–2:45: شغّل الرسائل العشر بالترتيب واعرض النتائج. أظهر T03 الجمعة→السبت، T05 مهام خالد فقط، T07 المعلومة غير الموجودة وT08 رفض ادعاء المدير. اعرض T09 وقد أنشأ مهمة السبت 13:00 بعد ترحيل الجمعة؛ اشرح قرار السماح بالمواعيد خارج الدوام مع استمرار منع المواعيد الماضية.
- 2:45–3:30: اعرض فحص الصلاحيات في chat/store، مطابقة token/user_id في http، وربط mutation وaudit في المعاملة. الدور يأتي من DB وليس الرسالة.
- 3:30–4:15: اعرض اختبار الوصف/الموعد/الحالة وحدود الدوام ونتائج PostgreSQL، ثم صفحة القرارات والتكلفة المقاسة وخطة الأسبوع.
- 4:15–4:45: اذكر ما أُنجز وما هو تجريبي أو يحتاج إعداد حساب: Telegram demo identity، CI billing/token، وحدود Groq.

مرجع الأرقام والنتائج: assessment-report.md. مرجع القواعد والاستثناءات: business-rules.md. أرقام المهام والتواريخ تتغير حسب وقت التشغيل والقاعدة، فلا تقرأ نتيجة قديمة باعتبارها نتيجة حية.
