# 03 — صفحة القرارات

**المشروع:** مساعد المهام الذكي بالعربية — **تاريخ التقدير:** 14 أكتوبر 2026

## لماذا هذه الأدوات؟

- **Node.js 22:** لتنفيذ خادم API وتكامل تيليجرام بلغة واحدة، مع HTTP وfetch المدمجين وتقليل الاعتماديات.
- **PostgreSQL محليًا وNeon سحابيًا:** لحفظ الموظفين والمهام والطلبات وسجل العمليات، واستخدام المعاملات لمنع تعارض الموافقات وتكرار التسجيل. نفس منطق الخادم يعمل محليًا وسحابيًا.
- **Groq مع Qwen 3.8 27B:** لفهم العربية الفصحى واللهجة والصيغ المختلفة، واستخراج النية والحقول في JSON مضبوط. إعداد النموذج قابل للتغيير دون تعديل منطق الأعمال.
- **Docker وVercel وتيليجرام:** Docker لتشغيل قابل للتكرار، وVercel لنشر API، وتيليجرام لواجهة محادثة وأزرار حسب الدور. GitHub لحفظ المصدر وإعداد الاختبارات والنشر.

## كيف نضمن الالتزام؟

النموذج يستخلص الطلب فقط؛ الخادم يراجع الهوية والدور من قاعدة البيانات، ويتحقق من الصلاحيات والتواريخ والاعتمادات قبل التنفيذ. الاستعلامات نفسها تحدّ نطاق الموظف أو القسم، وتُحفظ التعديلات وسجل العمليات في معاملة واحدة. إجابات السياسة تُرجع نص البنود المختارة؛ المعلومة الغائبة تستدعي توضيحًا أو اعتذارًا دون اختراع قاعدة.

التوقيت المعتمد **Asia/Riyadh**. الجمعة تُرحّل للسبت بنفس الساعة. مواعيد المهام مسموحة خارج الدوام، ولا تُنشأ بمواعيد ماضية؛ تحديث الحالة مسموح يومياً، قبل موعدها أو بعده وفي الأيام التالية، ولكن قبل نهاية دوام يوم التحديث: 16:00 من الأحد للخميس و12:00 السبت؛ الجمعة عطلة. التعديلات اللاحقة على السياسة موثقة في [قواعد النظام](business-rules.md).

## التكلفة الشهرية: 100 موظف × 20 رسالة يوميًا

افتراض محافظ: **30 يومًا × 100 × 20 = 60,000 رسالة شهريًا**، وكل رسالة تستدعي النموذج مرة واحدة. سعر النموذج المنشور: **0.80 دولار لكل مليون رمز إدخال، و4 دولارات لكل مليون رمز إخراج**، وفق [Groq](https://console.groq.com/docs/model/qwen/qwen3.8-27b).

عينة التشغيل الفعلي للرسائل العشر سجلت متوسط **2,419.2 رمز إدخال و105 رموز إخراج** لكل استدعاء:

`60,000 × (2,419.2 × 0.80 + 105 × 4) ÷ 1,000,000 = 141.32 دولار شهريًا`

| بند الميزانية | التقدير الشهري بالدولار |
|---|---:|
| الذكاء الاصطناعي حسب متوسط العينة | 141.32 |
| احتياطي 20% لتغير السياق والمحاولات المدفوعة | 28.26 |
| استضافة وقاعدة بيانات ومراقبة ونسخ احتياطي | 20–50 |
| **الإجمالي التخطيطي** | **189.59–219.59** |

تكلفة البنية التحتية مخصص تقديري مبني على أسعار السوق الحالية. عند 22 يوم تشغيل، تقدير الذكاء الاصطناعي وحده **103.64 دولار**. لا يشمل الإجمالي الضرائب أو الاشتراكات الإضافية أو وقت التشغيل البشري.

## ماذا أحسّن لو توفر أسبوع إضافي؟

1. **اليومان 1–2:** توسيع اختبارات العربية والسياق، وإضافة جلسات API لجمع المعلومات الناقصة بين الرسائل.
2. **اليوم 3:** تحديد طلب الاعتماد بالاسم أو النوع عند وجود طلب وحيد ضمن الصلاحيات، وإلا طلب رقم واضح.
3. **اليوم 4:** مفاتيح منع تكرار طلبات API وحدود الاستخدام على مستوى التطبيق.
4. **اليوم 5:** ترحيلات قاعدة بيانات بإصدارات، وتجربة الاستعادة وتنظيم الاحتفاظ بالتقارير الطبية.
5. **اليومان 6–7:** مراقبة التكلفة والزمن والأخطاء واختبار السعة، واستكمال متطلبات CI/CD وتشغيل بوابات التحقق والتسليم.

**حالة التسليم:** 56 اختبارًا آليًا — 53 نجاحًا بالتشغيل الافتراضي وصفر فشل، و56/56 مع PostgreSQL الحقيقي. جميع الرسائل العشر نجحت عبر Groq وHTTP وقاعدة بيانات حقيقية. Telegram يدعم وضع التجربة (demo_id) المصرح به صراحة ووضع الهوية الموثوقة (secure_link)؛ كلاهما مطبق ومختبر. CI/CD مهيأ عبر GitHub Actions ومتصل بـ Vercel؛ التفعيل الكامل يتطلب إضافة VERCEL_TOKEN في أسرار بيئة الإنتاج على GitHub. النشر عبر Vercel CLI موثق ومختبر ويعمل. فيديو الشرح 3–5 دقائق: النص والترتيب والأوامر الجاهزة في docs/video-script-ar.md — يُسجّل بصوت صاحب المشروع.
